# Протокол сенсорної рукавиці

Рукавиця підключається до окремого COM-порту. Порт роботизованої кисті використовується лише для вихідних команд і не повинен збігатися з портом рукавиці.

## Базові параметри

- типове значення: 115200 бод;
- завершення пакета: `\n`;
- рекомендована частота: 30–100 пакетів за секунду;
- значення можуть бути цілими або дробовими;
- кількість каналів задається в налаштуваннях;
- старі пакети не накопичуються для керування — використовується найновіший стан.

## Формат масиву

```text
[120,540,1024,2500,3300,3700,4095]
```

Підходить для найпростішої прошивки. Додатковий текст до або після масиву ігнорується в режимі автоматичного розпізнавання.

## Формат CSV

```text
120,540,1024,2500,3300,3700,4095
```

Також допускаються пробіли або крапка з комою як роздільник.

## Префіксований формат

```text
@GLV1,00125,7,120,540,1024,2500,3300,3700,4095*ABCD
```

Де:

- `GLV1` — назва й версія протоколу;
- `00125` — номер пакета;
- `7` — кількість каналів;
- наступні значення — дані датчиків;
- `ABCD` — необов’язкова контрольна сума прошивки рукавиці.

Поточний застосунок відокремлює масив значень, але не вимагає конкретного алгоритму контрольної суми для вхідної рукавиці. Це дозволяє використовувати власну прошивку.

## Нормалізація

Для візуалізації використовується глобальний діапазон `input_min…input_max`. Для фактичного керування кожна вісь має незалежні параметри:

- `glove_channel` — номер елемента масиву;
- `glove_min` — сире значення відкритого положення;
- `glove_max` — сире значення повного згину;
- `glove_inverted` — інверсія датчика.

Нормалізоване значення обмежується діапазоном `0.0…1.0`, після чого перетворюється на механічний діапазон відповідного сервопривода.

## Приклад прошивки передавача

```cpp
void loop() {
  int values[7];
  for (int i = 0; i < 7; ++i) {
    values[i] = analogRead(sensorPins[i]);
  }

  Serial.print('[');
  for (int i = 0; i < 7; ++i) {
    if (i) Serial.print(',');
    Serial.print(values[i]);
  }
  Serial.println(']');
  delay(20);
}
```

Перед використанням потрібно оголосити `sensorPins` відповідно до контролера рукавиці.
