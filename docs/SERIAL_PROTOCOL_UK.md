# Serial-протокол «Є-Рука»

## Параметри за замовчуванням

- 115200 бод;
- 8 біт даних;
- без парності;
- 1 стоп-біт;
- 60 пакетів на секунду;
- завершення пакета `LF` (`\n`).

## Простий формат

```text
[90,45,90,90,90,90,90]\n
```

Порядок значень визначається активним профілем. Формат зручний для налагодження, але не має номера пакета й контрольної суми.

## Захищений формат YR1

```text
@YR1,00125,7,90,45,90,90,90,90,90*D7DC\n
```

Поля:

- `@` — початок;
- `YR1` — версія;
- `00125` — номер пакета modulo 100000;
- `7` — кількість значень у стандартному профілі;
- значення каналів;
- `*D7DC` — CRC16-CCITT payload між `@` та `*`;
- `\n` — кінець.

Параметри CRC: polynomial `0x1021`, initial value `0xFFFF`, без xor-out.

## Відповіді ESP32

```text
!READY,YR1
!ACK,00125
!ERR,CRC
!ERR,COUNT
!ERR,RANGE
!ERR,FORMAT
!ERR,OVERFLOW
!SAFE,TIMEOUT
```

ACK необов’язковий. При 30–50 пакетах/с його краще вимкнути, якщо зворотна телеметрія не потрібна.

## Безпека

ESP32 повинна перевірити кількість значень, CRC, діапазони й таймаут. Пошкоджений пакет не повинен частково оновлювати серви.
