# Робота з проєктом у Codex

Проєкт містить `AGENTS.md`, `.codex/config.toml`, `PLANS.md`, архітектурний опис, єдиний Python-інструмент команд і GitHub Actions. Codex автоматично читає `AGENTS.md` із кореня репозиторію.

## Локальний Codex на Windows

1. Розпакуйте проєкт у звичайну папку без кириличних проблемних шляхів, наприклад `D:\Projects\Ye-Ruka`.
2. Запустіть `python tools/project.py setup`.
3. Перевірте проєкт через `python tools/project.py check`.
4. Встановіть Codex app, розширення для редактора або Codex CLI.
5. Відкрийте саме кореневу папку, де лежать `AGENTS.md` і `pyproject.toml`.
6. Для CLI відкрийте термінал у корені проєкту й запустіть `codex`.

Перед великим завданням попросіть Codex спочатку скласти план за `PLANS.md`. Для однієї задачі використовуйте один окремий потік або Git worktree.

## Codex Cloud

1. Створіть Git-репозиторій і завантажте цей проєкт на GitHub.
2. У Codex підключіть GitHub і надайте доступ лише до потрібного репозиторію.
3. У налаштуваннях середовища задайте встановлення:

```bash
python -m pip install --upgrade pip
python -m pip install -e ".[test]"
```

4. Команда перевірки:

```bash
python -m compileall -q src tests tools && python -m pytest
```

Cloud-середовище не має фізичної камери, COM-портів або сервоприводів. Такі зміни Codex повинен перевіряти моками й тестами, а фізичну перевірку потрібно виконувати локально.

## Приклад нормальної задачі

```text
Goal: виправити адаптивність сторінки рукавиці при 125–200% DPI.
Context: src/ye_ruka/ui/pages/glove.py, ui/widgets/visualizers.py, resources/styles/*.qss.
Constraints: не змінювати протокол рукавиці, не блокувати GUI, не використовувати fixed size для основного контенту.
Done when: немає обрізаного тексту при 1120×720, обидві теми працюють, тести проходять, CHANGELOG оновлено.
```

## Перед прийняттям змін

Перегляньте diff, запустіть `python tools/project.py check`, потім `python tools/project.py debug`. Для змін Serial або безпеки окремо перевірте симуляцію без підключеної ESP32, а фізичні серви тестуйте з вимкненим навантаженням і малими діапазонами.
