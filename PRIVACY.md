# Privacy Policy

Effective date: June 15, 2026

Ye-Ruka is designed to operate locally on the user's Windows computer.

## Data processed locally

- camera frames used for hand tracking;
- COM-port data exchanged with ESP32 devices and a sensor glove;
- calibration, theme, language, and connection settings;
- local diagnostic messages shown inside the application.

Camera frames and serial data are not uploaded by the application. Ye-Ruka does not include analytics, advertising, user accounts, or background telemetry.

## Files and settings

Application settings are stored in the current Windows user profile. They can be reset from the application or removed during troubleshooting. The uninstaller removes program files; user-created configuration backups remain under the user's control.

## Network access

The installed application does not require a cloud service for hand control. GitHub is used separately to host source code, documentation, the project website, and release downloads, and GitHub's own privacy terms apply to those services.

## Contact

Privacy questions can be submitted through the repository's [issue tracker](https://github.com/Oleksii1221/Ye-ruka/issues).
