# Security Policy

## Supported versions

Security and safety fixes are provided for the latest published release.

## Reporting a vulnerability

Do not publish credentials, private logs, device identifiers, or an exploitable vulnerability in a public issue. Use GitHub's private vulnerability reporting feature when available, or contact the maintainer through the GitHub profile linked to this repository.

Include the affected version, reproduction steps, expected impact, and whether the issue can command physical hardware unexpectedly. Reports involving unsafe servo movement, bypassed limits, arbitrary command execution, or malicious firmware are treated as high priority.

## Hardware safety

Software safety controls cannot replace mechanical stops, correct power design, fusing, an accessible emergency stop, and supervised testing. Disconnect actuator power before changing wiring. Test new firmware without mechanical load first.
