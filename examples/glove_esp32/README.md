# Приклад передавача сенсорної рукавиці на ESP32

Прошивка читає сім аналогових каналів і передає їх масивом із частотою 50 Гц:

```text
[123,840,1024,2050,3070,3500,4095]
```

Стандартні піни: `32, 33, 34, 35, 36, 39, 25`. Змініть `SENSOR_PINS` відповідно до своєї плати. Швидкість повинна збігатися з параметром сторінки «Рукавиця» — типово 115200 бод.

Після підключення відкрийте сторінку «Рукавиця», виберіть окремий COM-порт, формат «Автовизначення» та діапазон 0…4095. Потім відкалібруйте мінімум і максимум кожного каналу в налаштуваннях рукавиці.
