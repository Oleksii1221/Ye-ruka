# Є-Рука: сервісна прошивка ESP32

Ця прошивка призначена лише для калібрування сервоприводів DS3225.

- Одночасно активна лише одна серва.
- Команда руху: `servo angle`, наприклад `1 30`.
- Діапазон сирого кута: `-90..90` градусів від центру.
- Команда `off` відключає активну серву.
- Для звичайної роботи після калібрування поверніть робочу прошивку через застосунок Є-Рука.

Не тримайте руки біля механізму та забезпечте окреме живлення сервоприводів.
