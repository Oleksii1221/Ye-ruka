# MediaPipe model notice

The repository does not require the binary model to be committed. `tools/download_models.py` downloads the recommended Hand Landmarker model bundle from the official Google MediaPipe model storage.

Source URL:

`https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task`

Review the applicable model terms before redistributing the binary as part of a commercial package. The default build script includes the locally downloaded file in the EXE folder.
