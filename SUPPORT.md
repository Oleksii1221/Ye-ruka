# Support

Before opening an issue:

1. Install the latest release.
2. Read [Troubleshooting](docs/TROUBLESHOOTING_UK.md).
3. Confirm the selected COM port is not open in Arduino IDE, Serial Monitor, or another copy of Ye-Ruka.
4. Reproduce the issue with actuator power disabled when possible.

Use the [bug report form](https://github.com/Oleksii1221/Ye-ruka/issues/new/choose) and attach the application version, Windows version, ESP32 model, relevant logs, and clear steps. Remove personal paths and device identifiers before posting.

Feature requests are welcome but do not guarantee implementation or a release date.
